# Image Catalog — WeChat Theme Frontend

参考配图库。当使用本 skill 构建网页但还没有真实的产品截图时，可从此目录中挑选合适比例的占位图/配图来展示。每个文件夹里的 4 张图是同一主题的同一构图，分别裁成 4 种比例，可按版面需要直接选用。

## 比例 → 适用版位

| 文件名 | 实际像素 | 比例 | 典型用途 |
|---|---|---|---|
| `16-9.jpg` | 3488×1962 | 16:9 | Hero 区大幅插图、`.news-card__image`（默认 16:9）、视频封面 |
| `2.35-1.jpg` | 900×383 | 2.35:1 | 电影级超宽 banner、`.cta-band` 顶部装饰带、页面顶部强调条 |
| `3-2.jpg` | 2940~5472×1962~3648 | 3:2 | 单卡/产品截图、轮播大图、自由版面 |
| `4-3.jpg` | 2616×1962 | 4:3 | 较方的产品截图、功能演示图、`.hero-band__illustration`（默认 4:3） |

> **注意**：页面组件的默认 `aspect-ratio` 不一定与图源匹配。选用后请用 CSS `object-fit: cover` 配合 `aspect-ratio` 容器裁切，避免拉伸变形。本 skill 的 `.news-card__image` 默认就是 `16:9`，可直接用 `16-9.jpg` 完美匹配；`.hero-band__illustration` 默认 `4:3`，可直接用 `4-3.jpg`。

## 按主题 / 场景选图

### splash（`splash/`）
- **画面**：手握手机，屏幕中是地球/太空壁纸（启动 splash 视觉）
- **寓意**：连接、开始、首次体验
- **推荐版位**：下载/引导页的 hero 插图、产品"新功能发布"配图
- **不推荐**：与"暗夜/夜间"相关的主题（该图为浅色背景）

### wechat（`wechat/`）
- **画面**：绿色（品牌色）背景上的微信 logo 与人物剪影
- **寓意**：品牌露出、品牌认知、核心标识
- **推荐版位**：品牌故事页 hero、新闻稿顶部配图
- **特殊用法**：可与 `.cta-band-green` 绿色 CTA 组合，形成"绿+绿"主视觉（需注意对比度，可叠加深色文字层或半透明遮罩）

## 选用决策树

```
需要配图吗？
├─ 否 → 用 CSS 占位（`background: var(--color-surface-soft)` + 文字）
└─ 是
   ├─ 什么位置？
   │  ├─ Hero 大插图（半屏以上）→ 优先 16-9.jpg（与 16:9 容器完美匹配）
   │  ├─ 卡片缩略图 → 优先 16-9.jpg（与 .news-card__image 16:9 默认匹配）
   │  ├─ 方形/近方形象 → 优先 4-3.jpg
   │  ├─ 超宽 banner → 优先 2.35-1.jpg
   │  └─ 自由版面（无 aspect-ratio 约束）→ 3-2.jpg（最灵活，可裁）
   └─ 什么主题？
      ├─ 启动/连接/首次体验 → splash/
      └─ 品牌/核心标识 → wechat/
```

## 暗色模式兼容提示

- **splash**（浅色背景）：在暗色页面上自然突出，可直接使用
- **wechat**（绿色主图）：与 `--color-primary` 呼应，是暗色模式下最契合的配图
- 如果需要在暗色页面展示"夜间使用场景"的截图，可使用 CSS 滤镜（`filter: brightness(0.85)`）让浅色配图融入暗色背景
