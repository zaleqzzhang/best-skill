## 功能介绍

**全网热榜分析技能**是一款面向舆情分析师、产品运营人员的智能分析工具，能够实时获取全网各平台热榜数据，并通过多维度分析框架生成专业的舆情研判报告。

本技能整合了**国家"十五五"规划纲要**作为宏观政策分析框架，使舆情分析具备国家战略视角，覆盖现代化产业体系、科技自立自强、数字中国等 18 篇 62 章政策领域。

## 四种分析模式

### 模式一：全网热榜分析（默认）

从全网热榜中遴选 **20 条**最具深度研究价值的舆情选题，适用于每日舆情概览。

**使用示例**：
- "帮我分析一下今天的热榜"
- "生成今日舆情选题列表"
- "今天有哪些值得关注的热点"

### 模式二：主体舆情分析

针对用户指定的**特定人物、企业、产品、品牌**等主体，从热榜中筛选并分析与其相关的舆情信息。

**支持的主体类型**：
- 👤 人物：企业家（马化腾、雷军等）、公众人物、政治人物、意见领袖
- 🏢 企业/机构：腾讯、字节跳动、阿里巴巴等
- 📱 产品/品牌：小米汽车、微信、抖音等
- 🏭 行业/领域：可作为辅助限定条件

**使用示例**：
- "分析腾讯相关舆情"
- "看看马化腾今天有什么热点"
- "小米汽车相关的舆论分析"

### 模式三：事件深度分析

对单一舆情事件从 **8 个维度**进行全方位深度研判：

1. **事件概述** — 时间线、核心人物、关键节点
2. **传播态势分析** — 首发平台、传播路径、热度趋势
3. **多方立场梳理** — 利益相关方立场、博弈关系
4. **舆论场分析** — 主流民意、观点派系、情绪分布
5. **风险研判** — 风险等级、升级路径、次生舆情
6. **历史关联与背景** — 类似事件对比、宏观政策背景
7. **走势预判** — 短期/中期走势、情景推演
8. **应对建议** — 应对策略、舆论引导要点

**使用示例**：
- "深入分析一下 Claude Code 源码泄露事件"
- "这个事件的传播态势和风险如何"
- "对XX事件做一个详细的舆情研判"

### 模式四：产品舆情监控

面向**产品线运营人员**，从产品运营视角监控产品口碑、用户反馈、竞品动态和市场机会。

**与模式二的区别**：模式二以舆情分析师视角关注整体舆论态势，模式四以产品运营视角关注可执行的运营洞察和行动建议。

**6 大运营分析维度**：用户口碑影响、运营关注等级、影响面分析、竞品信号、运营建议、舆情走势

**使用示例**：
- "我是微信的运营，帮我看看今天的舆情"
- "帮我监控一下飞书的用户反馈和竞品动态"
- "作为抖音的产品运营，今天有什么舆情需要处理"

## 输出格式

本技能支持两种输出格式，可根据需求灵活选择：

### Markdown 文本报告（党政风）

输出格式规范的 Markdown 文本报告，适合直接阅读和汇报。

- 采用**党政风**写作风格：语言庄重严谨、用词规范权威
- 使用四字短语和对仗结构，杜绝网络用语和情绪化表达
- 体现政务信息研判的专业性

### JSON 格式

直接输出结构化 JSON 数据，适合程序化处理和二次加工。

- 从 `{` 开始，不包裹任何 Markdown 代码块
- 包含 `policy_relevance` 字段标注事件与"十五五"规划的关联关系

**切换方式**：在对话中明确要求即可，例如：
- "用文本报告格式输出"
- "生成 Markdown 报告"
- "输出文字版分析"

## 使用步骤

### 第一步：选择分析模式

直接用自然语言描述你的需求，技能会自动识别并选择合适的分析模式：

| 你的需求 | 自动匹配模式 |
|----------|-------------|
| "分析今天的热榜" | 模式一：全网热榜分析 |
| "分析腾讯相关舆情" | 模式二：主体舆情分析 |
| "深入分析XX事件" | 模式三：事件深度分析 |
| "我是XX产品运营，看看舆情" | 模式四：产品舆情监控 |

### 第二步：等待数据获取与分析

技能会自动：
1. 调用热榜聚合服务 API 获取实时数据
2. 根据分析模式加载对应的分析规则
3. 加载"十五五"规划宏观政策框架
4. 执行多维度分析研判

### 第三步：获取分析报告

- 默认输出 JSON 格式报告
- 如需文本报告，在对话中注明"输出文本报告"或"Markdown 格式"即可

### 第四步：深入探索（可选）

- 从全网热榜分析结果中选取某条话题，要求进行事件深度分析
- 从主体分析结果中选取感兴趣的事件，进一步深入研判
- 切换不同的输出格式查看同一分析结果
