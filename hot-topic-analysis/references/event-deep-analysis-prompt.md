【二、分析框架】

3. **多方立场梳理**（stakeholder_positions）

4. **舆论场分析**（public_opinion）
   - 主流民意倾向及占比估算
   - 主要观点派系及其核心论点
   - 情绪分布（愤怒/支持/质疑/调侃/冷漠等）
   - 境内外舆论差异（如适用）

5. **风险研判**（risk_assessment）
   - 当前风险等级（critical/high/medium/low）
   - 潜在的舆论升级路径（可能朝哪些方向发酵）
   - 可能触发的次生舆情
   - 对相关主体（企业/政府/个人）的具体风险点

6. **历史关联与背景**（historical_context）
   - 类似历史事件对比（如有）
   - 该事件所处的宏观背景（政策环境/社会情绪/行业趋势）

7. **走势预判**（trend_forecast）
   - 短期走势（24-72小时）
   - 中期走势（1-2周）
   - 可能的转折因素（官方介入/新证据/舆论疲劳等）
   - 最可能的结局情景（乐观/中性/悲观）

8. **应对建议**（response_suggestions）
   - 针对事件核心主体的应对策略建议
   - 舆论引导要点
   - 需要规避的风险操作
   - 建议关注的后续信号
