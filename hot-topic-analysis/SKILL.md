- 涉及"十五五"规划重点领域的事件，在分析中体现政策背景和宏观意义
- JSON 输出中通过 `policy_relevance` 字段标注事件与规划的关联关系

## 分析模式

本技能支持四种分析模式，根据用户需求自动选择：

### 模式一：全网热榜分析（默认）

当用户要求分析当日热榜、生成舆情选题列表时使用。从全网热榜中遴选20条最具研究价值的话题。

**分析流程**：
1. 调用 `/api/v1/all-items` 获取全量去重热搜数据，可通过 `/api/wordcloud` 辅助了解当日热词分布
2. 读取 [references/analysis-prompt.md](references/analysis-prompt.md) 获取完整分析规则和输出格式
3. 读取 [references/shiwuwu-policy-framework.md](references/shiwuwu-policy-framework.md) 获取宏观政策参照框架
4. 按照分析规则对热榜数据进行筛选、评估和撰写，涉及规划重点领域的事件适当加权
5. 默认输出 Markdown 文本报告格式（党政风），若用户明确要求 JSON 格式则输出纯 JSON

### 模式二：主体舆情分析

当用户指定了特定的分析主体（如"分析腾讯相关舆情""看看马化腾今天有什么热点""小米汽车相关的舆论"等）时使用。从热榜中筛选与该主体相关的所有话题，进行关联分析和影响研判。

**支持的主体类型**：
- 人物：企业家（马化腾、雷军等）、公众人物、政治人物、意见领袖等
- 企业/机构：腾讯、字节跳动、阿里巴巴等
- 产品/品牌：小米汽车、微信、抖音等
- 行业/领域：可作为辅助限定条件

**分析流程**：
1. 调用 `/api/v1/all-items` 获取全量去重热搜数据；若主体为腾讯或腾讯系，额外调用 `/api/tencent-today` 获取专项数据；可结合 `/api/search` 按主体关键词精准检索补充
2. 读取 [references/subject-analysis-prompt.md](references/subject-analysis-prompt.md) 获取主体分析规则和输出格式
3. 读取 [references/shiwuwu-policy-framework.md](references/shiwuwu-policy-framework.md) 获取宏观政策参照框架
4. 识别用户指定的主体，从热榜数据中筛选所有与该主体直接或间接相关的话题
5. 对每条话题进行关联类型判定、情感倾向分析、影响等级评估和宏观政策关联标注
6. 默认输出 Markdown 文本报告格式（党政风），若用户明确要求 JSON 格式则输出纯 JSON

### 模式三：事件深度分析

当用户要求对某一具体舆情事件进行深入分析（如"深入分析一下Claude Code源码泄露事件""帮我详细分析这个热点""这个事件的舆情风险如何"等）时使用。对单一事件从8个维度进行全方位深度研判。

**触发场景示例**：
- "帮我深入分析一下XX事件"
- "这个事件的传播态势和风险如何"
- "对XX事件做一个详细的舆情研判"
- "分析一下XX事件的各方立场和走势"
- 用户从模式一/模式二的结果中选取某条话题要求深入分析

**8大分析维度**：
1. 事件概述——完整还原事件时间线、核心人物和关键节点
2. 传播态势分析——首发平台、传播路径、传播速度、热度趋势
3. 多方立场梳理——利益相关方的立场、表态、博弈关系
4. 舆论场分析——主流民意、观点派系、情绪分布、境内外差异
5. 风险研判——风险等级、升级路径、次生舆情、具体风险点
6. 历史关联与背景——类似事件对比、宏观背景、关联热点
7. 走势预判——短期/中期走势、转折因素、情景推演
8. 应对建议——应对策略、舆论引导要点、风险规避、后续信号

**分析流程**：
1. 调用 `/api/v1/all-items` 获取全量去重热搜数据，结合 `/api/search` 按事件关键词搜索相关条目，使用 `/api/wordcloud` 了解当日舆论场热词分布以辅助背景分析
2. 读取 [references/event-deep-analysis-prompt.md](references/event-deep-analysis-prompt.md) 获取事件深度分析规则和输出格式
3. 读取 [references/shiwuwu-policy-framework.md](references/shiwuwu-policy-framework.md) 获取宏观政策参照框架
4. 从热榜数据中定位与该事件相关的所有条目，聚合多平台信息
5. 按照8大分析维度逐一进行深度研判，在"历史关联与背景"维度中融入国家战略框架分析
6. 默认输出 Markdown 文本报告格式（党政风），若用户明确要求 JSON 格式则输出纯 JSON

### 模式四：产品舆情监控

当用户以产品运营身份关注某个产品的舆情动态时使用（如"帮我看看微信今天的舆情""作为飞书的运营，帮我监控下产品相关的热点""我负责抖音运营，今天有什么需要关注的"等）。从产品运营视角出发，重点关注用户口碑、功能反馈、竞品威胁和市场机会。

**与模式二的核心区别**：
- 模式二（主体舆情分析）：以舆情分析师视角，关注主体的整体舆论态势和影响
- 模式四（产品舆情监控）：以产品运营视角，关注可执行的运营洞察和行动建议

**触发场景示例**：
- "我是XX产品的运营，帮我看看今天的舆情"
- "帮我监控一下XX产品的用户反馈和竞品动态"
- "XX产品今天有什么需要运营关注的热点"
- "作为XX的产品运营，今天有什么舆情需要处理"

**产品画像配置**：
- 产品名称（必需）+ 别称、所属企业、核心功能、竞品列表、目标用户群（可选）
- 若用户未提供完整信息，自动补全常识性信息

**6大运营分析维度**：
1. 用户口碑影响——事件对产品口碑的影响方向和程度
2. 运营关注等级——urgent（紧急）/ high（高）/ medium（中）/ low（低）
3. 影响面分析——受影响的用户群体、功能模块、业务指标
4. 竞品信号——竞品威胁或市场机会识别
5. 运营建议——具体的运营动作建议（官方回应/功能优化/借势营销/危机公关等）
6. 舆情走势——话题热度趋势判断

**6大关联类型**：
- 产品直接相关、母公司关联、竞品动态、用户反馈、行业政策、生态关联

**排序规则**：按运营关注等级优先排序（urgent > high > medium > low）

**分析流程**：
1. 调用 `/api/v1/all-items` 获取全量去重热搜数据；若监控腾讯系产品，额外调用 `/api/tencent-today` 获取专项数据；结合 `/api/search` 搜索产品名称和竞品关键词补充数据
2. 读取 [references/product-monitor-prompt.md](references/product-monitor-prompt.md) 获取产品舆情监控规则和输出格式
3. 读取 [references/shiwuwu-policy-framework.md](references/shiwuwu-policy-framework.md) 获取宏观政策参照框架
4. 识别用户指定的产品，自动构建产品画像（补全竞品、核心功能等信息）
5. 从热榜数据中筛选所有与该产品相关的话题（含竞品动态和行业政策）
6. 对每条话题进行运营视角的多维度分析（口碑影响、关注等级、竞品信号、运营建议等），行业政策类事件结合宏观政策框架分析
7. 按运营关注等级排序输出
8. 默认输出 Markdown 文本报告格式（党政风），若用户明确要求 JSON 格式则输出纯 JSON

## 输出要求

四种分析模式均支持以下两种输出格式：

### Markdown 文本报告格式（党政风）——默认输出格式
- **所有模式默认输出 Markdown 文本报告**，无需用户额外指定
- 采用**党政风**写作风格：语言庄重严谨、用词规范权威，使用四字短语和对仗结构，杜绝网络用语和情绪化表达，体现政务信息研判的专业性
- **行文格式要求**：报告正文必须以连贯的段落形式呈现，严禁使用编号列表（1. 2. 3.）或无序列表（- ）来罗列内容，每个分析维度应写成完整流畅的文章段落（信息来源部分除外）
- 使用标准 Markdown 语法，包含所有字段内容
- **所有信息来源必须包含可点击的跳转链接**，使用 Markdown 链接语法 `[标题](url)` 呈现，确保读者可直接跳转至原文
- 全网热榜分析模式：输出20条话题
- 主体舆情分析模式：输出与主体相关的所有话题（最多20条），额外包含关联类型、情感倾向、影响等级等字段
- 事件深度分析模式：输出完整的8维度分析报告，包含风险等级标识、情景推演、应对建议等
- 产品舆情监控模式：输出舆情概览仪表盘 + 按关注等级分组的话题列表，每条含运营建议和竞品信号标识

### JSON 格式（用户明确要求时使用）
- 仅当用户明确要求输出 JSON 格式时使用
- 直接输出纯JSON，从 `{` 开始，不包裹任何 markdown 代码块
- **所有 sources 中的 url 字段必须填写实际链接地址**，不可为空字符串
- 全网热榜分析模式：输出20条话题
- 主体舆情分析模式：输出与主体相关的所有话题（最多20条）
- 事件深度分析模式：输出单一事件的8维度深度分析报告
- 产品舆情监控模式：输出与产品相关的所有话题（最多20条），含舆情概览统计
